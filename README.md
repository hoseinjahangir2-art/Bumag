# Bumag Android

Capacitor-based Android shell. **Not the final workout app.**

The intended workout is the user's previously written **professional three-day split**. The exact exercise prescription has not yet been recovered; do not replace it with the unrelated 12-session full-body program.

## APK build
Open GitHub Actions → Build Android APK → Run workflow. Download the `Bumag-debug-apk` artifact after a successful run. This is a debug APK, not a signed release build.
